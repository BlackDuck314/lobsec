    - Input: PDF file (binary) — use pdfplumber for table extraction
    - Metrics: dubai|dxb_total_passengers, dubai|dxb_arrivals, dubai|dxb_departures, dubai|dxb_transit
    - Target pages: first 3-5 pages of factsheet (summary tables)
    - Table detection: look for headers containing "Passengers", "Arrivals", "Departures", "Transit"
    - Extract numeric values, strip commas, convert to int
    - measurement_date: start of month from report metadata
    - Validate: total_passengers > 100000 (sanity check — DXB handles millions/month)

    **normalize_gdrfa.py** (COLL-08):
    - Input: PDF file (binary) — use pdfplumber for table extraction
    - Metrics: dubai|gdrfa_total_issued, dubai|gdrfa_employment_visa, dubai|gdrfa_golden_visa, dubai|gdrfa_family_visa, dubai|gdrfa_total_cancelled, dubai|gdrfa_net_flow
    - Target pages 2-5 (visa statistics tables typically on these pages)
    - Table detection: headers containing "Visa" + "Issued", "Cancellation", "Golden Visa"
    - net_flow = total_issued - total_cancelled
    - measurement_date: start of quarter from PDF metadata or filename
    - Per CONTEXT: when extraction fails, output error JSON for Telegram manual-entry fallback. Error should include PDF URL and required field names.
    - Follow the detailed pdfplumber pattern from 08-RESEARCH.md code example

    **normalize_khda.py** (COLL-09):
    - Input: PDF file (binary) — use pdfplumber for table extraction
    - Metrics: dubai|khda_total_enrollment, dubai|khda_enrollment_{curriculum} (for: british, american, indian, ib, ministry), dubai|khda_withdrawal_rate
    - Target pages: look for enrollment summary tables (typically first 10 pages)
    - Table detection: headers containing "Enrollment", "Students", "Curriculum", "Schools"
    - measurement_date: start of academic year (September of year)
    - Validate: total_enrollment > 100000 (Dubai has ~300K+ private school students)
    - Per CONTEXT: test against 2024-25 published report

    **normalize_rta.py** (COLL-10):
    - Input: JSON file with browser-extracted table data from Dubai Pulse
    - Metrics: dubai|rta_new_registrations, dubai|rta_deregistrations, dubai|rta_total_registered, dubai|rta_net_change
    - net_change = new_registrations - deregistrations
    - measurement_date: start of month from data
    - Validate: new_registrations >= 0, deregistrations >= 0

    **normalize_remittances.py** (COLL-13):
    - Input: PDF file (binary) — use pdfplumber for table extraction
    - Metrics: uae|cbuae_personal_remittances, uae|cbuae_workers_remittances, uae|cbuae_total_outflows
    - Per CONTEXT: extract ALL tables from full PDF via pdfplumber, filter for remittance data during normalization
    - Table detection: headers containing "Remittance", "Personal Transfers", "Workers", "Balance of Payments"
    - measurement_date: start of quarter from report metadata
    - Values in millions AED (standard CBUAE reporting unit)

    - Import and call their pandera schema validator before processing
