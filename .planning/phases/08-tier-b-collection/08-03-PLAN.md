    **collect.sh** — Create standalone orchestrator script at /opt/lobsec/bin/collect.sh:

    Per CONTEXT:
    - Usage: `collect.sh weekly|monthly|quarterly|{source-name}`
    - Sources /opt/lobsec/.env for environment variables
    - Verifies Ninja Scraper is running (curl http://127.0.0.1:18791/health)
    - Calls Node.js CLI: `node /opt/lobsec/plugins/lobsec-uae-re/dist/cli.js run-frequency $FREQUENCY` or `run-one $SOURCE`
    - Logs start/end timestamps to /opt/lobsec/logs/collection.log
    - Matches existing gateway-chat.sh pattern

    Script structure:
    ```bash
    #!/bin/bash
    # /opt/lobsec/bin/collect.sh
    # UAE RE collection orchestrator
    # Trigger chain: systemd timer → this script → Node CLI → CollectorRegistry → Ninja Scraper → Python normalization

    set -euo pipefail

    FREQUENCY="${1:-}"
    LOG_DIR="/opt/lobsec/logs"
    NODE_BIN="/opt/lobsec/plugins/lobsec-uae-re/dist/cli.js"

    # Validate argument
    if [[ -z "$FREQUENCY" ]]; then
        echo "Usage: $0 <weekly|monthly|quarterly|source-name>" >&2
        exit 1
    fi

    # Source environment
    if [[ -f /opt/lobsec/.env ]]; then
        set -a
        source /opt/lobsec/.env
        set +a
    fi

    # Health check
    if ! curl -sf http://127.0.0.1:18791/health >/dev/null 2>&1; then
        echo "[$(date -Iseconds)] ERROR: Ninja Scraper not responding at 127.0.0.1:18791" | tee -a "$LOG_DIR/collection.log" >&2
        exit 1
    fi

    # Determine command
    VALID_FREQUENCIES="weekly monthly quarterly daily"
    if echo "$VALID_FREQUENCIES" | grep -qw "$FREQUENCY"; then
        CMD="run-frequency"
    else
        CMD="run-one"
    fi

    echo "[$(date -Iseconds)] Starting collection: $CMD $FREQUENCY" | tee -a "$LOG_DIR/collection.log"

    node "$NODE_BIN" "$CMD" "$FREQUENCY" 2>&1 | tee -a "$LOG_DIR/collection.log"
    EXIT_CODE=${PIPESTATUS[0]}

    echo "[$(date -Iseconds)] Collection finished: $CMD $FREQUENCY (exit $EXIT_CODE)" | tee -a "$LOG_DIR/collection.log"

    exit $EXIT_CODE
    ```

    Make executable: chmod +x /opt/lobsec/bin/collect.sh

    Note: This script runs as lobsec user via systemd. The .env file provides SCRAPER_AUTH_TOKEN and UAE_RE_DATA_DIR. The Node CLI (cli.ts) already handles: init DB, create collectors, run by frequency, auto-trigger normalization, log results.
