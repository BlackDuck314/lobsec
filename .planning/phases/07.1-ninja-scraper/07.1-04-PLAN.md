<task type="auto">
  <name>Task 1: Deploy Ninja Scraper service to production</name>
  <files>
    packages/scraper/deploy.sh
  </files>
  <action>
    Create `packages/scraper/deploy.sh` deployment script and execute it. The script should handle everything needed to get the scraper running in production.

    **Step 1: Create Python venv:**
    ```bash
    sudo -u lobsec python3.13 -m venv /opt/lobsec/scraper-venv
    sudo -u lobsec /opt/lobsec/scraper-venv/bin/pip install --upgrade pip
    ```

    **Step 2: Install dependencies:**
    ```bash
    sudo -u lobsec /opt/lobsec/scraper-venv/bin/pip install \
      'crawlee[playwright]' patchright fastapi 'uvicorn[standard]' \
      pyyaml httpx tenacity structlog 'pydantic>=2.0'
    ```

    **Step 3: Install Patchright Chromium browser:**
    ```bash
    # Set browser path to lobsec-accessible directory
    export PLAYWRIGHT_BROWSERS_PATH=/opt/lobsec/scraper-venv/browsers
    sudo -u lobsec mkdir -p /opt/lobsec/scraper-venv/browsers
    sudo -u lobsec /opt/lobsec/scraper-venv/bin/patchright install chromium
    ```
    Verify browser exists: `ls /opt/lobsec/scraper-venv/browsers/chromium-*/`

    **Step 4: Deploy package code:**
    ```bash
    sudo mkdir -p /opt/lobsec/scraper
    sudo cp -r packages/scraper/src/ninja_scraper /opt/lobsec/scraper/
    sudo cp -r packages/scraper/missions /opt/lobsec/scraper/
    sudo chown -R lobsec:lobsec /opt/lobsec/scraper
    ```

    **Step 5: Generate and store auth token in HSM:**
    ```bash
    # Generate random token
    SCRAPER_TOKEN=$(openssl rand -hex 32)

    # Store in HSM
    echo -n "$SCRAPER_TOKEN" > /tmp/scraper-token.bin
    pkcs11-tool --module /usr/lib/softhsm/libsofthsm2.so \
      --token-label lobsec --pin $(cat /opt/lobsec/boot/pin.env | grep HSM_PIN | cut -d= -f2) \
      --write-object /tmp/scraper-token.bin \
      --type data --label scraper-auth-token --id 0E
    rm /tmp/scraper-token.bin
    chown -R lobsec:lobsec /opt/lobsec/hsm/tokens/

    # Add to .env for systemd (idempotent — only append if not already present)
    grep -q '^SCRAPER_AUTH_TOKEN=' /opt/lobsec/.env 2>/dev/null || echo "SCRAPER_AUTH_TOKEN=$SCRAPER_TOKEN" >> /opt/lobsec/.env
    ```
    NOTE: The `grep -q` check prevents duplicate entries on re-deployment. If the token already exists in .env and needs to be rotated, use `sed -i` to replace it instead of appending.

    **Step 6: Create systemd unit file `/etc/systemd/system/lobsec-scraper.service`:**
    ```ini
    [Unit]
    Description=Ninja Scraper - lobsec web scraping engine
    After=network.target lobsec.service
    Wants=lobsec.service

    [Service]
    Type=simple
    User=lobsec
    Group=lobsec
    WorkingDirectory=/opt/lobsec/scraper

    # Source .env for auth token, then start uvicorn
    ExecStart=/bin/bash -c 'source /opt/lobsec/.env && exec /opt/lobsec/scraper-venv/bin/uvicorn ninja_scraper.api.main:app --host 127.0.0.1 --port 18791'

    Restart=on-failure
    RestartSec=10

    # Environment
    Environment=PYTHONPATH=/opt/lobsec/scraper
    Environment=MISSIONS_DIR=/opt/lobsec/scraper/missions
    Environment=PLAYWRIGHT_BROWSERS_PATH=/opt/lobsec/scraper-venv/browsers
    Environment=CRAWLEE_STORAGE_DIR=/opt/lobsec/data/raw/crawlee-storage

    # Hardening (same as other lobsec services)
    NoNewPrivileges=true
    ProtectSystem=strict
    ProtectHome=true
    ReadWritePaths=/opt/lobsec/data /opt/lobsec/scraper-venv /opt/lobsec/logs
    PrivateTmp=true
    CapabilityBoundingSet=

    [Install]
    WantedBy=multi-user.target
    ```

    **Step 7: Start and verify:**
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable lobsec-scraper
    sudo systemctl start lobsec-scraper
    sleep 3
    # Health check
    curl -s http://127.0.0.1:18791/health | python3 -m json.tool
    # Should return: {"status": "ok", "missions_loaded": 7, "version": "1.0.0"}
    ```

    **Step 8: Verify missions loaded:**
    ```bash
    TOKEN=$(grep SCRAPER_AUTH_TOKEN /opt/lobsec/.env | cut -d= -f2)
    curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:18791/missions | python3 -m json.tool
    ```

    **Step 9: Ensure raw data output directories exist:**
    ```bash
    sudo -u lobsec mkdir -p /opt/lobsec/data/raw/{dld-sales,ejari-rentals,building-permits,adrec-abu-dhabi,bayut-listings,propertyfinder-listings,dewa-connections,crawlee-storage}
    ```

    **Step 10: Add SCRAPER_AUTH_TOKEN to the uae-re plugin's environment** so CollectorRegistry can authenticate to the scraper. Update lobsec.service ExecStart bash wrapper or .env to include the token.

    **Gotchas to handle:**
    - ProtectSystem=strict + ReadWritePaths must include /opt/lobsec/data
    - PLAYWRIGHT_BROWSERS_PATH must be set in systemd env (not just shell)
    - After HSM write as root, chown lobsec:lobsec /opt/lobsec/hsm/tokens/
    - If Patchright needs system deps (libgbm, libasound2, etc.), install them: `apt install -y libgbm1 libasound2t64 libatk-bridge2.0-0 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 libxrandr2`
    - **IMPORTANT (.env persistence):** lobsec.service ExecStopPost may wipe .env on stop. Verify that lobsec-scraper.service sources .env independently via its own ExecStart bash wrapper (not dependent on lobsec.service .env lifecycle). If lobsec.service wipes .env, the scraper service must have its own environment loading mechanism or use a separate .env file (e.g., /opt/lobsec/scraper.env)
