<!-- Ninja Scraper API contract from Plan 01 -->
Ninja Scraper API at http://127.0.0.1:18791:
- POST /crawl { mission_name: string, params?: dict } -> { job_id: string, status: "queued" }
- GET /crawl/{job_id} -> { job_id, status: "queued"|"running"|"completed"|"failed", result?: { file_path, row_count, duration_ms, error } }
- GET /health -> { status: "ok", missions_loaded: N }
- All endpoints require Bearer token except /health

    **Step 3: Refactor SourceCollector base class:**
    The collect() method is no longer abstract. Instead, SourceCollector is now a concrete class that:
    1. Has a `missionName` property (string) set in constructor
    2. In `collect()`:
       a. POST to `${baseUrl}/crawl` with body `{ mission_name: this.missionName, params: {} }` and Bearer token header
       b. Get job_id from response
       c. Poll `${baseUrl}/crawl/${job_id}` every pollIntervalMs
       d. When status is "completed": extract file_path and row_count from result
       e. When status is "failed": throw Error with result.error
       f. If polling exceeds maxWaitMs: throw timeout error
       g. Return { filePath, rowCount }
    3. Use Node.js native `fetch()` (available in Node 22) — do NOT add any HTTP client dependency
    4. The `run()` method stays unchanged (wraps collect() in circuit breaker + retry + logging)
    5. Constructor now takes: metadata (CollectorMetadata), db (Database), scraperConfig (ScraperApiConfig)
    6. Remove the `abstract` keyword from the class and `collect()` method
