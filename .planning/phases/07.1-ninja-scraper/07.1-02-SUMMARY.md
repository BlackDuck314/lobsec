## Decisions Made
- DLD and Ejari missions download the same Dubai Pulse CSV independently (separate audit trails, per architecture decision)
- ADREC replaces DARI/UAE Pass per user decision; uses click-to-download pattern with 4 export button IDs
- Bayut uses abbreviated slugs (jvc, jbr, jlt) while PropertyFinder uses full slugs (jumeirah-village-circle, jumeirah-beach-residence, jumeirah-lake-towers)
- Area iteration is sequential within a single mission; max_concurrent config applies to concurrent missions at the scheduler level
- Handler wraps all exceptions in MissionResult to prevent mission crashes from bringing down the service
