    Create 9 Python files following the exact bridge contract patterns from collect_trends.py (collector) and normalize_remittances.py (normalizer).

    **collect_worldbank.py** — DirectPythonCollector for World Bank API:
    - Fetch 5 indicators for UAE (country code ARE) from `https://api.worldbank.org/v2/country/ARE/indicator/{CODE}?format=json&per_page=50&date=2000:2026`
    - Indicator codes: NY.GDP.MKTP.KD.ZG (GDP growth %), FP.CPI.TOTL.ZG (CPI inflation %), BX.KLT.DINV.CD.WD (FDI inflows USD), NE.TRD.GNFS.ZS (trade % GDP), SP.POP.TOTL (population)
    - Response is JSON array: `[pagination_meta, [records...]]`. Each record has `date` (year string) and `value` (float or null).
    - Skip records where `value is None` (data not yet available for that year).
    - Save to `{outputDir}/worldbank-macro/{today}.json` with structure: `{collectedAt, indicators: {label: [records]}}`
    - Return `{filePath, rowCount}` on stdout. Use `requests` library with `timeout=30`.

    **collect_imf.py** — DirectPythonCollector for IMF DataMapper API:
    - Fetch 6 indicators for UAE from `https://www.imf.org/external/datamapper/api/v1/{CODE}/ARE`
    - Codes: NGDP_RPCH (GDP growth), PCPIPCH (inflation), BCA_NGDPD (current account % GDP), LP (population millions), NGDPD (GDP USD bn), LUR (unemployment %)
    - Response is nested JSON: `{values: {CODE: {ARE: {YEAR: VALUE}}}}`
    - No pagination needed. Single response per indicator.
    - Save to `{outputDir}/imf-weo/{today}.json` with structure: `{collectedAt, indicators: {code: {year: value}}}`
    - Return `{filePath, rowCount}` on stdout.

    **collect_dfm_stocks.py** — DirectPythonCollector for Yahoo Finance v8 API:
    - Fetch 4 DFM RE stocks: EMAAR.AE, EMAARDEV.AE, DEYAAR.AE, UPP.AE
    - URL: `https://query1.finance.yahoo.com/v8/finance/chart/{SYMBOL}?interval=1mo&range=5y`
    - MUST include User-Agent header: `Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36`
    - Response: `chart.result[0].timestamp` (Unix seconds array) + `chart.result[0].indicators.quote[0]` (open/high/low/close/volume arrays)
    - Convert timestamps with `datetime.fromtimestamp(ts, tz=timezone.utc)`
    - Save to `{outputDir}/dfm-stocks/{today}.json` with structure: `{collectedAt, stocks: {symbol: {timestamps, ohlcv}}}`
    - Return `{filePath, rowCount}`.

    **normalize_worldbank.py** — Normalizer:
    - Read raw JSON. For each indicator, extract records where value is not null.
    - World Bank dates are year strings ("2024"). Set `measurement_date` = `{year}-01-01`.
    - Metric names: `uae|wb_gdp_growth_pct`, `uae|wb_cpi_inflation_pct`, `uae|wb_fdi_inflows_usd`, `uae|wb_trade_pct_gdp`, `uae|wb_population`
    - Map indicator codes to labels using dict in the collector's output.
    - Return list of NormalizedRecord dicts (no `source` field — main() adds it from stdin input).
    - Use `available_date` from `collectedAt` in the raw JSON.

    **normalize_imf.py** — Normalizer with forecast separation:
    - Read raw JSON. For each indicator code, iterate year:value pairs.
    - CRITICAL: Separate historical from forecast data. Years <= current year (2026) get metric prefix `uae|imf_weo_`, years > current year get `uae|imf_weo_forecast_`.
    - Metric names for historical: `uae|imf_weo_gdp_growth_pct`, `uae|imf_weo_inflation_pct`, `uae|imf_weo_current_account_pct_gdp`, `uae|imf_weo_population_mn`, `uae|imf_weo_gdp_usd_bn`, `uae|imf_weo_unemployment_pct`
    - Metric names for forecasts: same but with `forecast_` after `imf_weo_` (e.g., `uae|imf_weo_forecast_gdp_growth_pct`)
    - Set `measurement_date` = `{year}-01-01`.
    - Use `datetime.now().year` to determine the cutoff (not hardcoded 2026).

    **normalize_dfm_stocks.py** — Normalizer:
    - Read raw JSON. For each stock symbol, pair timestamps with close prices and volumes.
    - Convert Unix timestamps to `YYYY-MM-01` for measurement_date (monthly data, first of month).
    - Skip entries where close is None (holiday months with no trading).
    - Metric names use lowercase symbol prefix: `uae|dfm_emaar_close`, `uae|dfm_emaar_volume`, `uae|dfm_emaardev_close`, `uae|dfm_emaardev_volume`, `uae|dfm_deyaar_close`, `uae|dfm_deyaar_volume`, `uae|dfm_upp_close`, `uae|dfm_upp_volume`
    - Symbol-to-label mapping: EMAAR.AE->emaar, EMAARDEV.AE->emaardev, DEYAAR.AE->deyaar, UPP.AE->upp

    **Schema files** (worldbank_schema.py, imf_schema.py, dfm_stocks_schema.py):
    - Follow the pattern from remittances_schema.py — simple file existence + basic format validation.
    - worldbank: validate JSON file exists, loads, has "indicators" key
    - imf: validate JSON file exists, loads, has "indicators" key
    - dfm_stocks: validate JSON file exists, loads, has "stocks" key

    All collectors and normalizers follow the stdin/stdout JSON bridge contract. All use `if __name__ == "__main__": main()` entry point.
