    **Part A: PMI Python collector + normalizer + schema**

    **collect_pmi.py** — DirectPythonCollector for S&P Global PMI:
    - This source requires Ninja Scraper because pmi.spglobal.com is behind AWS WAF.
    - The collector calls the Ninja Scraper API to run the "spglobal-pmi" mission (not a YAML file — create it inline or use the scraper's generic crawl endpoint).
    - ALTERNATIVE APPROACH (simpler, more reliable): Use `requests` to call the Ninja Scraper HTTP API directly from Python, since the scraper handles the browser automation:
      1. POST to `http://127.0.0.1:18791/crawl` with body `{"mission_name": "spglobal-pmi", "force": true}` and Bearer auth token from `SCRAPER_AUTH_TOKEN` env var
      2. Poll GET `/crawl/{job_id}` until status is "completed"
      3. Read the downloaded file (HTML with embedded PDF links, or raw PDF)
    - HOWEVER, if the scraper mission doesn't exist yet, use a FALLBACK approach:
      1. Try direct HTTP request to `https://www.pmi.spglobal.com/Public/Release/PressReleases` with browser User-Agent
      2. If that fails (AWS WAF 202/403), try fetching a known PMI release PDF URL
      3. If all fail, save an empty result and log a warning — PMI is the lowest-priority of the 4 macro sources
    - For PDF extraction: use pdfplumber to extract text from first 2 pages, then regex for the headline PMI number
    - PMI number pattern: look for a 2-digit number with one decimal between 40.0 and 65.0 near keywords "PMI", "UAE", "Seasonally Adjusted"
    - Save to `{outputDir}/spglobal-pmi/{today}.json` with structure: `{collectedAt, pmi_value: float|null, release_date: str|null, pdf_path: str|null}`
    - Return `{filePath, rowCount}` where rowCount is 1 if PMI extracted, 0 if not.

    **normalize_pmi.py** — Normalizer (simple — single metric):
    - Read raw JSON. If `pmi_value` is null, return empty list.
    - Single metric: `uae|spglobal_pmi_headline` with value = pmi_value.
    - Set `measurement_date` to first of the month from `collectedAt`.
    - Standard normalizer bridge contract (stdin JSON, stdout JSON list).

    **pmi_schema.py** — Schema validation:
    - Validate JSON file exists, loads, has "collectedAt" key.
    - If `pmi_value` is present, validate it's between 30.0 and 70.0 (reasonable PMI range).
