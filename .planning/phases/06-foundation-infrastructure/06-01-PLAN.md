       - main: `dist/index.js`, types: `dist/index.d.ts`

       - outDir: `dist`, rootDir: `src`

    4. Create `packages/uae-re/python/requirements.txt` with pinned versions:
       ```
       pandas==2.2.3

       vaderSentiment==3.3.2

       ```

    5. Create Python package skeleton in `packages/uae-re/python/uae_re/`:
       - `__init__.py`: Module docstring, version string
       - `normalize.py`: Entry point for monthly resampling. Reads JSON from stdin, creates DataFrame, resamples with `resample('ME').mean()`, forward-fills with limit=1, outputs JSON to stdout. All logging to stderr.
       - `stationarity.py`: ADF + KPSS stationarity testing entry point. Reads series from stdin JSON, runs `adfuller()` and `kpss()`, returns test statistics, p-values, and recommendation. Both tests must agree for stationary verdict.
       - `granger.py`: Granger causality testing entry point. Reads two series from stdin JSON, checks stationarity first (hard gate), runs `grangercausalitytests()` with maxlag, returns F-statistics and p-values.
       - `correlation.py`: Cross-correlation lag detection. Reads two series, computes `pearsonr` for lags 1-12 months, returns optimal lag and correlation coefficient.

       Each Python module must follow the bridge pattern:
       - Read JSON from `sys.stdin`
       - All debug/log output to `sys.stderr`
       - Write result JSON to `sys.stdout` with `flush=True`
       - Guard with `if __name__ == '__main__': main()`

    6. Run `pnpm install` from monorepo root to link the new workspace package.

    7. Verify Python 3.13 is available: `python3 --version`
