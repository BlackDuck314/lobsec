       - Export `CollectionResult`: success (boolean), rowCount? (number), filePath? (string), error? (string), duration (number in ms)
       - Export `CollectorStatus = 'idle' | 'running' | 'stale' | 'failed'`
       - Export `CollectorInfo`: metadata (CollectorMetadata), status (CollectorStatus), lastRun? (string ISO date), consecutiveFailures (number)
       - Export `RegistryRunResult`: results (Map&lt;string, CollectionResult&gt;), totalDuration (number), successCount (number), failureCount (number)

    2. Create `packages/uae-re/src/collectors/base.ts`:
       - Import `retryWithBackoff`, `CircuitBreaker`, `DEFAULT_RETRY_CONFIG` from `@lobsec/shared`
       - Import `insertCollectionLog`, `insertRawSource` from `../db/queries.js`
       - Import `Database` type from `better-sqlite3`
       - Import types from `./types.js`

       - Export abstract class `SourceCollector`:
         - `readonly metadata: CollectorMetadata`
         - `protected db: Database.Database`
         - `protected circuitBreaker: CircuitBreaker`
         - `status: CollectorStatus = 'idle'`
         - `consecutiveFailures: number = 0`
         - `lastRun?: string`

         Constructor takes `metadata: CollectorMetadata` and `db: Database.Database`. Creates CircuitBreaker with `{ failureThreshold: 3, resetTimeoutMs: 30_000, halfOpenSuccesses: 1 }`.

         Abstract method: `abstract collect(): Promise<{ filePath: string; rowCount: number }>`

         Protected method `validateResult(result: { filePath: string; rowCount: number }): void`:
           - Throws if `filePath` is empty
           - Throws if `rowCount < 0`
           - Throws if `rowCount === 0` with warning (empty collection)
           This provides schema validation and error propagation per INFRA-03.

         Public method `async run(): Promise<CollectionResult>`:
           - Sets `status = 'running'`
           - Records start time
           - Uses `retryWithBackoff` wrapping `circuitBreaker.execute(() => this.collect())` with `{ ...DEFAULT_RETRY_CONFIG, maxRetries: 3 }`
           - On success: calls `validateResult()`, calls `insertCollectionLog(db, { source, status: 'success', rowCount, durationMs, error: null })`, resets `consecutiveFailures = 0`, sets `status = 'idle'`, records `lastRun`
           - On failure: calls `insertCollectionLog(db, { source, status: 'failure', rowCount: null, durationMs, error })`, increments `consecutiveFailures`, sets `status = consecutiveFailures >= 2 ? 'stale' : 'failed'`
           - Returns `CollectionResult` with duration

         Public method `getInfo(): CollectorInfo` — returns current state snapshot.

    3. Create `packages/uae-re/src/collectors/registry.ts`:
       - Import `SourceCollector` from `./base.js`
       - Import types from `./types.js`

       - Export class `CollectorRegistry`:
         - Private `collectors: Map<string, SourceCollector>`
         - Private `activeTasks: number = 0`
         - Private readonly `maxConcurrency: number` (default 3, configurable via constructor)

         `register(collector: SourceCollector): void` — adds to map by metadata.source. Throws if duplicate source name.

         `unregister(source: string): boolean` — removes from map.

         `get(source: string): SourceCollector | undefined` — lookup by source name.

         `getAll(): CollectorInfo[]` — returns info for all registered collectors.

         `getByFrequency(frequency: CollectionFrequency): SourceCollector[]` — filters collectors by frequency.

         `async runAll(): Promise<RegistryRunResult>` — runs ALL registered collectors with concurrency control:
           - Sort by priority (1 = highest first)
           - Use a semaphore pattern: for each collector, wait until `activeTasks < maxConcurrency`, then increment and launch
           - Do NOT use polling (setTimeout loop). Instead use a proper semaphore with a resolve queue:
             ```
             private waitForSlot(): Promise<void> — returns when activeTasks < maxConcurrency
             private releaseSlot(): void — decrements activeTasks, resolves next waiter
             ```
           - Collect all results into Map<string, CollectionResult>
           - Return RegistryRunResult with summary stats

         `async runByFrequency(frequency: CollectionFrequency): Promise<RegistryRunResult>` — runs only collectors matching the given frequency.

         `async runOne(source: string): Promise<CollectionResult>` — runs a single collector by source name. Throws if not found.

       - Import `spawn` from `node:child_process`

       - Import types from `./types.js`

       - Export function `runPython<T>(scriptName: PythonScriptName, input: unknown, config?: Partial<BridgeConfig>): Promise<PythonResult<T>>`:
         - Resolve full config with defaults
         - Construct Python executable path: `{venvPath}/bin/python3`
         - Construct module invocation: `python3 -m uae_re.{scriptName}`
         - Set PYTHONPATH to the parent of the uae_re package directory (so `import uae_re.normalize` works)
         - Spawn subprocess with:
           - stdio: ['pipe', 'pipe', 'pipe']
           - env: { ...process.env, PYTHONPATH: pythonPkgDir }
           - cwd: pythonPkgDir
         - Write JSON.stringify(input) to stdin, then end stdin
         - Collect stdout and stderr as strings
         - Set up timeout via setTimeout:
           - On timeout: kill process with SIGTERM, wait 5s, if still alive SIGKILL
           - Return `{ success: false, error: 'Timeout after {ms}ms', stderr, durationMs }`
         - On process close:
           - Clear timeout
           - If exit code !== 0: return `{ success: false, error: stderr || 'Exit code {code}', exitCode: code, stderr, durationMs }`
           - Parse stdout as JSON:
             - On parse error: return `{ success: false, error: 'JSON parse error: {msg}', stderr, durationMs }`
             - On success: return `{ success: true, data: parsed, stderr, durationMs }`

       - Export function `checkPythonAvailable(config?: Partial<BridgeConfig>): Promise<{ available: boolean; version?: string; error?: string }>`:
         - Spawn `{venvPath}/bin/python3 --version`
         - Return version string on success, error on failure
         - Useful for health checks and deployment verification

       - Export function `checkDependencies(config?: Partial<BridgeConfig>): Promise<{ available: boolean; missing: string[]; error?: string }>`:
         - Spawn `{venvPath}/bin/python3 -c "import pandas; import statsmodels; import scipy; import numpy; import pdfplumber; import vaderSentiment; import praw; import pytrends; print('ok')"`
