**Step 1: Create analyze.sh** at `/opt/lobsec/bin/analyze.sh`:
```bash
#!/bin/bash
# /opt/lobsec/bin/analyze.sh
# UAE RE statistical analysis pipeline orchestrator
# Trigger chain: systemd timer → this script → Node CLI → Python analysis modules
# Usage: analyze.sh

set -euo pipefail

LOG_DIR="/opt/lobsec/logs"
NODE_BIN="/opt/lobsec/plugins/lobsec-uae-re/dist/cli.js"

# Source environment
if [[ -f /opt/lobsec/.env ]]; then
    set -a
    source /opt/lobsec/.env
    set +a
fi

echo "[$(date -Iseconds)] Starting analysis pipeline" | tee -a "$LOG_DIR/analyze.log"

node "$NODE_BIN" analyze 2>&1 | tee -a "$LOG_DIR/analyze.log"
EXIT_CODE=${PIPESTATUS[0]}

echo "[$(date -Iseconds)] Analysis pipeline finished (exit $EXIT_CODE)" | tee -a "$LOG_DIR/analyze.log"

exit $EXIT_CODE
```

Make executable: `chmod +x /opt/lobsec/bin/analyze.sh`
Set ownership: `chown lobsec:lobsec /opt/lobsec/bin/analyze.sh`

NOTE: No health check for Ninja Scraper (unlike collect.sh) — the analysis pipeline reads from SQLite, it doesn't call the scraper.

**Step 2: Create systemd timer** at `/etc/systemd/system/lobsec-uae-analyze.timer`:
```ini
[Unit]
Description=UAE RE Statistical Analysis Pipeline (25th 02:00 UTC / 06:00 GST)
After=lobsec.service

[Timer]
OnCalendar=*-*-25 02:00:00
Persistent=true
Unit=lobsec-uae-analyze.service

[Install]
WantedBy=timers.target
```

**Step 3: Create systemd service** at `/etc/systemd/system/lobsec-uae-analyze.service`:
```ini
[Unit]
Description=UAE RE Statistical Analysis Pipeline
After=lobsec.service

[Service]
Type=oneshot
User=lobsec
EnvironmentFile=/opt/lobsec/boot/pin.env
ExecStart=/opt/lobsec/bin/analyze.sh
TimeoutStartSec=3600
StandardOutput=append:/opt/lobsec/logs/analyze.log
StandardError=append:/opt/lobsec/logs/analyze.log

# Security hardening (match existing services)
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/lobsec
```

**Step 4: Build and deploy code**:
1. Build TypeScript: `cd /root/lobsec && pnpm --filter @lobsec/uae-re build`
2. Deploy compiled TS: `cp -r packages/uae-re/dist/* /opt/lobsec/plugins/lobsec-uae-re/dist/`
3. Deploy Python modules: `cp -r packages/uae-re/python/uae_re/* /opt/lobsec/plugins/lobsec-uae-re/python/uae_re/`
4. Fix ownership: `chown -R lobsec:lobsec /opt/lobsec/plugins/lobsec-uae-re/`
5. Clear Node compile cache: `rm -rf /tmp/node-compile-cache` (gotcha from MEMORY.md)

**Step 5: Migrate database schema**:
Run the gateway or CLI once to trigger `initSchema()` which creates the 5 new tables. Or manually create them:
`sudo -u lobsec node /opt/lobsec/plugins/lobsec-uae-re/dist/cli.js analyze 2>&1 | head -20`
This will create tables on first run and then attempt the pipeline (which will gracefully skip most steps due to insufficient data — expected).

