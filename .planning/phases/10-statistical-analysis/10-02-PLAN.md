**analyze_composite.py** — Composite index from Granger-validated signals.

Bridge input: `{"db_path": "/opt/lobsec/data/uae-re.db"}`
Bridge output: `{"areas_computed": int, "city_wide_score": float, "city_wide_zone": str}`

Implementation:
1. Connect to SQLite at db_path
2. Read significant Granger results: `SELECT signal_source, signal_metric, target, weight, best_lag FROM granger_results WHERE significant = 1 ORDER BY tested_at DESC` — take the MOST RECENT run's results (group by signal_source, signal_metric, target and take latest tested_at)
3. For each significant signal, fetch most recent 12 months of z-score normalized values from normalized_monthly
4. Z-score normalize using `scipy.stats.zscore` or `(s - s.mean()) / s.std()`
5. **Area-level computation** (per locked decision):
   - For each of the 20 areas: collect area-specific signals (listings, rent metrics from bayut/propertyfinder/ejari where data has area granularity)
   - City-wide signals (visa, GDP, airport, remittances — no area dimension) contribute to EVERY area composite AND the city-wide composite
   - Weighted average: `sum(weight_i * zscore_i) / sum(weight_i)` for available signals
   - Scale to [-1, +1] using `np.tanh(raw / 2)` (smooth saturation)
6. Determine zone: score <= -0.3 = "strong_sell", score >= 0.3 = "strong_buy", else "neutral"
7. Track coverage: component_count = signals with data, total_components = all significant signals applicable to this area
8. Write to composite_scores: `INSERT INTO composite_scores (area, score, zone, component_count, total_components, components_json, computed_at) VALUES (?, ?, ?, ?, ?, ?, datetime('now'))` — components_json = JSON array of `{"source": str, "metric": str, "weight": float, "zscore": float}`
9. Write 'dubai' city-wide composite first, then per-area
10. Write analysis_log entry (metadata only: areas_computed count, no raw scores — SEC-07)
11. Get list of 20 areas from `SELECT DISTINCT canonical_name FROM area_names WHERE emirate = 'dubai'`

**analyze_anomalies.py** — EWMA-based outlier detection.

Bridge input: `{"db_path": "/opt/lobsec/data/uae-re.db"}`
Bridge output: `{"flagged_count": int, "by_source": {"dewa": int, "gdrfa": int, "bayut": int}}`

Implementation:
1. Connect to SQLite at db_path
2. Define monitored signals (per STAT-06):
   - `("dewa", "disconnections")` — DEWA closures
   - `("gdrfa", "visa_cancellations")` — visa cancellations
   - `("bayut", "listing_count")` — listing volume (also check propertyfinder)
3. For each signal, fetch values from normalized_monthly ordered by measurement_date ASC (parameterized SQL)
4. If fewer than 12 observations, skip (need enough history for meaningful EWMA)
5. Compute EWMA using `pandas.Series.ewm(span=12, adjust=False)`:
   - ewma_mean = series.ewm(span=12, adjust=False).mean()
   - ewma_std = series.ewm(span=12, adjust=False).std()
   - z_scores = (series - ewma_mean) / ewma_std.replace(0, float('nan'))
6. Flag anomalies where |z_score| > 2.0 (threshold=2 std devs — Claude's discretion from RESEARCH.md)
7. Write flagged points to anomaly_flags: `INSERT INTO anomaly_flags (source, metric_name, measurement_date, value, z_score, flagged_at) VALUES (?, ?, ?, ?, ?, datetime('now'))` — parameterized SQL
8. Clear previous anomaly_flags for these sources before inserting (DELETE WHERE source = ? for each monitored source)
9. Write analysis_log entry (flagged_count only, no raw values — SEC-07)

**analyze_expat_funnel.py** — 10-stage lifecycle funnel with z-score aggregation.

Bridge input: `{"db_path": "/opt/lobsec/data/uae-re.db"}`
Bridge output: `{"stages": [...], "flow_rates": [...], "digest_text": str}`

Implementation:
1. Connect to SQLite at db_path
2. Define 10 stages with signal mappings (LOCKED from CONTEXT.md — non-negotiable):
   ```python
   STAGES = [
       {"name": "Awareness", "signals": [("trends", "expat_interest")]},
       {"name": "Job Search", "signals": [("jobs", "total_postings")]},
       {"name": "Visa", "signals": [("gdrfa", "visa_issuances")]},
       {"name": "Arrival", "signals": [("dxb", "passenger_arrivals")]},
       {"name": "Housing Search", "signals": [("bayut", "listing_count"), ("propertyfinder", "listing_count")]},
       {"name": "Lease Signed", "signals": [("ejari", "new_contracts")]},
       {"name": "Settlement", "signals": [("dewa", "new_connections"), ("khda", "total_enrollment")]},
       {"name": "Established", "signals": [("rta", "new_registrations"), ("remittances", "total_personal_remittances")]},
       {"name": "Dissatisfaction", "signals": [("sentiment", "bearish_ratio"), ("bayut", "listing_count")]},
       {"name": "Exit", "signals": [("gdrfa", "visa_cancellations"), ("dewa", "disconnections")]},
   ]
   ```
3. For each stage, for each signal:
   a. Fetch last 12+ months from normalized_monthly (parameterized SQL)
   b. If < 2 observations, skip signal (can't compute z-score)
   c. Compute z-score of most recent value: `(latest - mean) / std`
4. Stage score = average z-score of all available signals in that stage
5. **Flow rates** (per locked decision): For consecutive stages, compute conversion ratio = stage[n+1].score / stage[n].score. If denominator near zero, report as None
6. **Trend indicators**: Compare current stage scores to previous month's scores. Compute delta. Show up-arrow for positive delta, down-arrow for negative
7. Build result JSON with:
   - `stages`: array of `{"name": str, "score": float, "signal_count": int, "total_signals": int, "trend": "up"|"down"|"flat"}`
   - `flow_rates`: array of `{"from": str, "to": str, "ratio": float|null}`
   - `digest_text`: Telegram-friendly text funnel with arrows and up/down indicators vs last month (per locked decision):
     ```
     EXPAT LIFECYCLE FUNNEL
     1. Awareness     [+0.42] ^^^
     2. Job Search    [+0.31] ^^
     ...
     10. Exit         [-0.15] v

     Flow: Awareness->Job Search: 0.74 | Job Search->Visa: 0.89 | ...
     ```
8. Store in intelligence_cache: `INSERT OR REPLACE INTO intelligence_cache (cache_key, product, params_hash, result_json, created_at, expires_at) VALUES ('expat_funnel_latest', 'expat_funnel', ?, ?, datetime('now'), ?)` — expires_at = next 25th
9. For previous month comparison: query intelligence_cache for previous 'expat_funnel_latest' entry. If none, report all trends as "flat" (first run)
10. Write analysis_log entry (stage count, signals available count — SEC-07, no raw visa/salary data)
