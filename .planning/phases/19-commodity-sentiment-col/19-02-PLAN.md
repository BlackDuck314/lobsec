**1a. Create `collect_cbuae_expanded.py`:**

Collector that downloads CBUAE QER PDFs and extracts monetary/banking tables using pdfplumber.

**Architecture:**
- Hardcode the 5 known QER PDF URLs in a `QER_PDFS` list of tuples: `(quarter_label, url)`
  - Labels: "2025-Q4", "2025-Q3", "2025-Q2", "2025-Q1", "2024-Q4"
  - URLs: as listed in the interfaces section above
- For each PDF: download to memory (`io.BytesIO`), open with `pdfplumber.open()`
- Extract ALL tables from all pages (not just pages 19-21 -- page numbers shift between editions). Search for tables containing key terms.
- For money supply: find table where first column contains "M1" or "Money Supply". Extract M1, M2, M3 rows. Values are AED billions.
- For interest rates: find table or text with "Base Rate" or "EIBOR". Extract Base Rate and 3-month EIBOR. Values are percentages.
- For banking: find table containing "Total Assets" and "Gross Credit". Extract Total Assets, Gross Credit, Deposits. Values are AED billions.

**Table parsing strategy:**
- Use `page.extract_tables()` on every page
- For each table, check if any cell in the first column matches known keywords
- Keywords for money supply: "M1", "Narrow Money", "Broad Money", "M2", "M3"
- Keywords for rates: "Base Rate", "EIBOR", "3-Month"
- Keywords for banking: "Total Assets", "Gross Credit", "Deposits"
- Extract the LAST numeric column (most recent quarter) for each metric
- Parse numeric values: strip commas, handle "n.a." or "-" as None

**Output format:** Write to `{outputDir}/cbuae-expanded/{date}.json`:
```json
{
  "collectedAt": "ISO timestamp",
  "quarters": {
    "2025-Q4": {
      "m1_aed_bn": 1033.0,
      "m2_aed_bn": 2589.0,
      "m3_aed_bn": 3123.0,
      "base_rate_pct": 3.90,
      "eibor_3m_pct": 4.28,
      "total_assets_aed_bn": 5200.0,
      "gross_credit_aed_bn": 2479.0,
      "bank_deposits_aed_bn": 3500.0
    },
    "2025-Q3": { ... },
    ...
  }
}
```

**Error handling:**
- If a PDF fails to download (403, 404), log warning and skip it (don't fail entire collection)
- If table extraction finds no matching keywords, log warning and produce null for that metric
- Use `timeout=60` on each PDF download (they're 1-5 MB)
- Use `User-Agent` header (same as Yahoo Finance) to avoid Cloudflare blocking on PDF download
- Wrap each PDF in try/except to isolate failures

**Bridge pattern:** Same stdin/stdout as all other collectors.

**1b. Create `normalize_cbuae_expanded.py`:**

Normalizer that converts raw CBUAE expanded JSON to normalized metrics.

- For each quarter in `data["quarters"]`:
  - Convert quarter label to measurement_date: "2025-Q4" -> "2025-10-01" (start of quarter month: Q1=01, Q2=04, Q3=07, Q4=10)
  - Produce 8 metrics per quarter (skip any with None values):
    - `uae|cbuae_m1_aed_bn`
    - `uae|cbuae_m2_aed_bn`
    - `uae|cbuae_m3_aed_bn`
    - `uae|cbuae_base_rate_pct`
    - `uae|cbuae_eibor_3m_pct`
    - `uae|cbuae_total_assets_aed_bn`
    - `uae|cbuae_gross_credit_aed_bn`
    - `uae|cbuae_bank_deposits_aed_bn`
  - available_date = collectedAt[:10]
- Same bridge pattern (stdin JSON in, stdout list out)

**Validation ranges** (log warnings if outside):
- M1: 200-3000 AED bn
- M2: 500-5000 AED bn
- M3: 600-6000 AED bn
- Base Rate: 0.0-10.0 %
- EIBOR 3m: 0.0-10.0 %
- Total Assets: 1000-10000 AED bn
- Gross Credit: 500-5000 AED bn
- Deposits: 500-8000 AED bn

**1c. Create `schemas/cbuae_expanded_schema.py`:**
- Validate JSON file exists, loads, has `"quarters"` key
- Validate `quarters` is a dict with at least 1 entry
- Same structural pattern as dfm_stocks_schema.py
