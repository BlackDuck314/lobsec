**Fix 2: uae_raw_data tool in index.ts (lines 698-783)**

1. Change the SQL query from:
   ```sql
   SELECT source, measurement_date, data_json FROM raw_sources WHERE source = ? AND measurement_date >= ? AND measurement_date <= ?
   ```
   To:
   ```sql
   SELECT source, measurement_date, metric_name, value FROM normalized_monthly WHERE source = ? AND measurement_date >= ? AND measurement_date <= ? ORDER BY measurement_date, metric_name
   ```

2. Change the result type from `Array<{source, measurement_date, data_json}>` to `Array<{source: string, measurement_date: string, metric_name: string, value: number}>`.

3. Replace the JSON.parse CSV generation (lines 743-768) with simple CSV from the row fields:
   ```typescript

   }
   ```

4. Update the tool description from "Returns raw data rows" to "Returns normalized data rows for a source in CSV format."

5. Keep the existing truncation logic (4000 char limit) and error handling unchanged.

Also update the `measurement_date` in the default start date calculation: the default range (12 months ago to today) is fine since normalized_monthly does have measurement_date.
