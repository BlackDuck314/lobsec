   ```bash
   sudo journalctl -u lobsec --since "30 minutes ago" --no-pager | grep -i "lobsec-uae-re"
   ```

3. **Data verification -- VERIF-02 pre-check:**
   Query the DB directly to confirm macro health will have data for 3+ groups:
   ```bash
   sudo -u lobsec sqlite3 /opt/lobsec/data/uae-re.db "
     SELECT source, metric_name, COUNT(*) as obs,
            MIN(measurement_date) as min_date,
            MAX(measurement_date) as max_date
     FROM normalized_monthly
     WHERE (source = 'mohre-permits' AND metric_name LIKE '%workforce_growth%')
        OR (source = 'dxb-passengers' AND metric_name LIKE '%annual_passengers%')
        OR (source = 'fcsa-demographics' AND metric_name LIKE '%total_population%')
     GROUP BY source, metric_name
   "
   ```
   Expected: 3 rows, each with obs >= 3 (minimum for z-score computation).

4. **Data verification -- VERIF-03 pre-check:**
   ```bash
   sudo -u lobsec sqlite3 /opt/lobsec/data/uae-re.db "
     SELECT source, MAX(timestamp) as last_success,
            ROUND(julianday('now') - julianday(MAX(timestamp)), 1) as days_ago
     FROM collection_log
     WHERE status = 'success'
     GROUP BY source
     HAVING days_ago <= 7
     ORDER BY last_success DESC
   "
   ```
   Expected: 7 sources with last successful run within 7 days.

5. **Gateway smoke test** (one quick tool call to verify the full chain):

   sudo -u lobsec /opt/lobsec/bin/gateway-chat.sh "What is the macro health dashboard status?"
