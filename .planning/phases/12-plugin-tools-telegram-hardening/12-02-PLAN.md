**1. Create `granger_ondemand.py`:**
Single-pair Granger causality test. Reads JSON from stdin, writes JSON to stdout.

Input format: `{ "signal": "bayut-listings|avg_asking_price", "target": "dld-sales|avg_price_per_sqft", "db_path": "/opt/lobsec/data/uae-re.db", "max_lag": 6 }`

Logic:
- Parse signal and target as `source|metric` (split on `|`)
- Open SQLite DB at db_path (read-only)
- Query `normalized_monthly` for both series: `SELECT measurement_date, value FROM normalized_monthly WHERE source = ? AND metric = ? ORDER BY measurement_date`
- Align both series on measurement_date (inner join on date)
- Require minimum 24 observations after alignment
- Run ADF stationarity test on both series. If non-stationary, difference once and re-test
- Run `statsmodels.tsa.stattools.grangercausalitytests(data, maxlag=max_lag)`
- Extract p-values for each lag, find best lag (minimum p-value)
- Apply Bonferroni correction: p_adjusted = p_raw * 1 (single test, no correction needed for on-demand)
- Format output as text:
  ```
  Granger Causality Test: {signal} → {target}
  Observations: {n}
  Best lag: {best_lag} months (p={p_value:.4f})
  Significant: {yes/no} (threshold: 0.05)

  All lags:
  Lag 1: p={p:.4f} {'*' if <0.05}
  Lag 2: p={p:.4f}
  ...
  ```
- Write JSON to stdout: `{ "output": "formatted text", "significant": true/false, "best_lag": N, "p_value": float }`

Error handling: catch all exceptions, write `{ "error": "message" }` to stdout.

Dependencies: sqlite3, json, sys, numpy, pandas, statsmodels (all in analytics-venv).

**2. Create `correlation_ondemand.py`:**
Single-pair cross-correlation analysis. Same stdin/stdout JSON pattern.

Input: `{ "signal": "bayut-listings|avg_asking_price", "target": "dld-sales|avg_price_per_sqft", "db_path": "/opt/lobsec/data/uae-re.db", "max_lag": 12 }`

Logic:
- Parse signal/target as `source|metric`
- Query normalized_monthly for both series (same as granger)
- Align on measurement_date, require >= 12 observations
- For lags 0 to max_lag: compute `scipy.stats.pearsonr(signal[:-lag], target[lag:])` (shift target forward by lag months)
- Find lag with highest absolute correlation
- Format output as text:
  ```
  Cross-Correlation: {signal} ↔ {target}
  Observations: {n}
  Best lag: {best_lag} months (r={correlation:.4f}, p={p_value:.4f})

  All lags:
  Lag 0: r={r:.4f} (p={p:.4f})
  Lag 1: r={r:.4f} (p={p:.4f})
  ...
  ```
- Write JSON to stdout: `{ "output": "formatted text", "best_lag": N, "correlation": float, "p_value": float }`

```typescript
function checkStaleness(sources: string[]): string {
  const warnings: string[] = [];
  for (const source of sources) {
    const gaps = detectGaps(db, source);
    if (gaps.length > 0) {
      warnings.push(`${source}: ${gaps[0].gapDays} days since last update`);
    }
  }
  return warnings.length > 0 ? `\n\nData freshness warning:\n${warnings.join("\n")}` : "";
}
```
