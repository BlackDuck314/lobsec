**Step 1: Compile lobsec-uae-re package**
```bash
cd /root/lobsec && npx tsc -p packages/uae-re/tsconfig.json
```

```bash
cd /root/lobsec/packages/uae-re && npx tsc --outDir dist --module nodenext --moduleResolution nodenext --target es2022 --strict --esModuleInterop src/index.ts src/tools/area-normalizer.ts src/analytics/types.ts src/collectors/base.ts
```
Verify compilation produces dist/ with all expected files including `tools/area-normalizer.js` and `analytics/granger_ondemand.py`, `analytics/correlation_ondemand.py`.

**Step 2: Compile lobsec-security package (credential redactor)**
```bash
cd /root/lobsec && npx tsc -p packages/plugin/tsconfig.json
```
Verify `dist/credential-redactor.js` contains the new patterns.

**Step 3: Deploy lobsec-uae-re to production**
```bash
# Copy compiled JS to production plugin directory
sudo cp -r /root/lobsec/packages/uae-re/dist/* /opt/lobsec/plugins/lobsec-uae-re/dist/

# Copy Python scripts (not compiled by tsc)
sudo cp /root/lobsec/packages/uae-re/src/analytics/granger_ondemand.py /opt/lobsec/plugins/lobsec-uae-re/dist/analytics/
sudo cp /root/lobsec/packages/uae-re/src/analytics/correlation_ondemand.py /opt/lobsec/plugins/lobsec-uae-re/dist/analytics/

# Fix ownership
sudo chown -R lobsec:lobsec /opt/lobsec/plugins/lobsec-uae-re/
```

**Step 4: Deploy credential redactor to production**
```bash
sudo cp /root/lobsec/packages/plugin/dist/credential-redactor.js /opt/lobsec/plugins/lobsec-security/dist/
sudo chown lobsec:lobsec /opt/lobsec/plugins/lobsec-security/dist/credential-redactor.js
```

**Step 5: Deploy nftables config**
```bash
# The updated nftables config (with domain documentation comments) was written in Plan 03
# Reload nftables to pick up changes
sudo nft -f /etc/nftables.d/lobsec-egress.conf
```

**Step 6: Deploy egress resolver script**
```bash
sudo cp /opt/lobsec/bin/update-egress-ips.sh /opt/lobsec/bin/update-egress-ips.sh 2>/dev/null || true
sudo chown lobsec:lobsec /opt/lobsec/bin/update-egress-ips.sh
sudo chmod +x /opt/lobsec/bin/update-egress-ips.sh
```

**Step 7: Clear Node.js compile cache and restart services**
```bash
# Clear compile cache (Node.js caches compiled modules)
sudo rm -rf /tmp/node-compile-cache

# Restart lobsec gateway to pick up new plugin tools
sudo systemctl restart lobsec

# Verify service started successfully
sleep 5
sudo systemctl is-active lobsec
sudo journalctl -u lobsec --no-pager -n 30 | grep -i 'uae-re\|registered\|error\|fail'
```

Verify in journal output that:
- `[lobsec-uae-re] registered 34 collectors + 14 tools` (or similar count)
- No errors during plugin registration
- Database initialized successfully

**Step 8: Verify tools are accessible**

