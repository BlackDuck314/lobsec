**1. ResolveResult interface:**
```typescript
export interface ResolveResult {
  canonical: string;
  confidence: "exact" | "alias" | "fuzzy";
  alternatives?: string[];   // for ambiguous fuzzy matches (>1 match)
  correctedFrom?: string;    // original input for inline correction message
}
```

**2. Alias table (ALIASES constant):**
Case-insensitive lookup. At minimum:
- JVC → Jumeirah Village Circle
- JBR → Jumeirah Beach Residence
- DIFC → Dubai International Financial Centre
- DIP → Dubai Investment Park
- JLT → Jumeirah Lake Towers
- MBR → Mohammed Bin Rashid City (MBR City)
- IMPZ → International Media Production Zone
- JAFZA → Jebel Ali Free Zone
- DSO → Dubai Silicon Oasis
- DHCC → Dubai Healthcare City
- DWC → Dubai World Central
- DIC → Dubai Internet City
- DMC → Dubai Media City
- KV → Knowledge Village
- SZR → Sheikh Zayed Road
- DAMAC → DAMAC Hills
- Add 5-10 more common abbreviations at discretion

**3. Hand-rolled Levenshtein function:**
Standard DP matrix implementation (~20 lines). No external dependency.

**4. resolveArea(input: string, db: Database) → ResolveResult | null:**
Resolution order:
1. Trim + uppercase → check ALIASES map → return with confidence "alias"
2. Case-insensitive exact match against `SELECT DISTINCT area FROM normalized_monthly` (use db query, NOT area_names table which may not have all areas) → return with confidence "exact"
3. Also check area_names table via `getCanonicalArea(db, input)` → return with confidence "exact"
4. Fuzzy: compute Levenshtein distance of `input.toLowerCase()` against all area names from step 2+3 combined. Filter to distance <= 2.
   - 0 matches → return null
   - 1 match → return `{ canonical: match, confidence: "fuzzy", correctedFrom: input }`
   - Multiple matches → return `{ canonical: bestMatch, confidence: "fuzzy", alternatives: allMatches, correctedFrom: input }`

Import Database type from "better-sqlite3". Import `getCanonicalArea` from `../areas/mapping.js`.

Do NOT use any external npm package for Levenshtein. The DP matrix is under 20 lines and handles all area name lengths (5-30 chars) easily.

**Shared helper function** (inside register(), after cache init):
```typescript
function resolveAreaOrError(input: string): { result: ResolveResult; prefix: string } | { error: string } {
  const resolved = resolveArea(input, db);
  if (!resolved) return { error: `Unknown area: "${input}". Use uae_collection_status() to see valid areas.` };
  if (resolved.alternatives && resolved.alternatives.length > 1) {
    return { error: `Ambiguous area "${input}". Did you mean:\n${resolved.alternatives.slice(0, 8).join("\n")}` };
  }
  const prefix = resolved.correctedFrom ? `Showing results for "${resolved.canonical}" (from "${resolved.correctedFrom}")\n\n` : "";
  return { result: resolved, prefix };
}
```
