**Part A: nftables domain whitelist (SEC-03)**

Per research recommendation: keep `tcp dport 443 accept` as functional gate (system is loopback-gated already), but add an IP set infrastructure and documented domain whitelist for defense-in-depth. This avoids operational fragility from CDN IP rotation while satisfying the domain documentation requirement.

1. Create `/opt/lobsec/bin/update-egress-ips.sh`:
```bash
#!/bin/bash
# Resolve UAE RE source domains to IP addresses for nftables IP set.
# Run periodically via cron/timer to handle CDN IP rotation.
# NOTE: lobsec_egress still has 'tcp dport 443 accept' as fallback.
# The IP set provides audit documentation, not hard enforcement.

set -euo pipefail

UAE_RE_DOMAINS=(
  # Tier A — Core Transaction Data
  "gateway.dubailand.gov.ae"      # DLD sales, Ejari rentals (Dubai Pulse)
  "data.bayanat.ae"               # Building permits (Dubai Pulse)
  "www.dubailand.gov.ae"          # DLD alternate
  "dashboard.adrec.gov.ae"        # ADREC Abu Dhabi
  "www.bayut.com"                 # Bayut listings
  "www.propertyfinder.ae"         # PropertyFinder listings
  "www.dewa.gov.ae"               # DEWA connections

  # Tier B — Government/Institutional
  "www.mohre.gov.ae"              # MOHRE work permits
  "www.dubaiairports.ae"          # DXB passengers
  "gdrfa.gov.ae"                  # GDRFA visas
  "www.khda.gov.ae"               # KHDA enrollment
  "www.rta.ae"                    # RTA vehicles + metro
  "www.centralbank.ae"            # CBUAE remittances + mortgages

  # Tier B — Job Platforms
  "www.linkedin.com"              # LinkedIn jobs
  "www.bayt.com"                  # Bayt jobs
  "ae.indeed.com"                 # Indeed jobs
  "www.gulftalent.com"            # GulfTalent jobs
  "www.cooperfitch.com"           # Cooper Fitch salary
  "www.hays.ae"                   # Hays salary
  "www.roberthalf.ae"             # Robert Half salary

  # Tier C — Alternative Signals
  "trends.google.com"             # Google Trends
  "oauth.reddit.com"              # Reddit OAuth
  "www.reddit.com"                # Reddit API
  "maps.googleapis.com"           # Google Maps
  "www.dtcm.gov.ae"               # DTCM tourism
  "www.dubaided.gov.ae"           # DED business licenses
  "www.dpworld.com"               # Jebel Ali port
  "www.zomato.com"                # F&B closures
  "data.insideairbnb.com"         # InsideAirbnb
  "www.jll-mena.com"              # JLL commercial
  "www.cbre.ae"                   # CBRE commercial
  "www.savills.ae"                # Savills commercial
  "www.dsc.gov.ae"                # DSC demographics

  # Infrastructure
  "api.anthropic.com"             # Claude API (via proxy)
  "api.telegram.org"              # Telegram Bot API
  "api.perplexity.ai"             # Perplexity web search
)

# Resolve and build IP list
TMPFILE=$(mktemp)
for domain in "${UAE_RE_DOMAINS[@]}"; do
  # Skip comments
  [[ "$domain" =~ ^# ]] && continue
  # Resolve A records
  dig +short "$domain" A 2>/dev/null | grep -E '^[0-9]+\.' >> "$TMPFILE" || true
done

# Deduplicate
sort -u "$TMPFILE" -o "$TMPFILE"

echo "# UAE RE egress whitelist — $(wc -l < "$TMPFILE") IPs from ${#UAE_RE_DOMAINS[@]} domains"
echo "# Generated: $(date -u +%Y-%m-%dT%H:%M:%SZ)"
echo "# Domains: ${UAE_RE_DOMAINS[*]}" | head -c 200
echo ""

# Log for audit trail
cp "$TMPFILE" /opt/lobsec/logs/egress-ips-latest.txt 2>/dev/null || true

rm -f "$TMPFILE"
echo "Domain resolution complete."
```

Make executable: `chmod +x /opt/lobsec/bin/update-egress-ips.sh`

**Part B: Audit logging (SEC-05)**

Edit `packages/uae-re/src/collectors/base.ts` to add audit logging after each collection run.

In the `run()` method of `SourceCollector`, after the collection result is determined (success or failure), append an audit entry:

```typescript
import fs from "node:fs";

// Inside run() method, after result is set:
const auditEntry = {
  type: "collection_run",
  timestamp: new Date().toISOString(),
  source: this.metadata.source,
  status: result.success ? "success" : "failure",
  rowCount: result.rowCount ?? 0,
  durationMs: result.durationMs,
  error: result.error ?? null,
};

try {
  fs.appendFileSync("/opt/lobsec/logs/audit.jsonl", JSON.stringify(auditEntry) + "\n");
} catch {
  // Audit logging failure must not crash collection
}
```

Read the current `base.ts` to find the exact location where `run()` returns the result. The audit append should go just before the return statement.

**CRITICAL**: Use `/opt/lobsec/logs/audit.jsonl` not `/tmp/` — `ProtectSystem=strict` blocks /tmp writes. The existing audit signing timer (lobsec-audit-sign.timer) already processes this file every 5 minutes.
