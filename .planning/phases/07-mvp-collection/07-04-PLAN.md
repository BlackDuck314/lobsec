  <action>
    **DEWA Collector:**

    1. **DEWAConnectionsCollector** (dewa-connections.ts):
       - Extend SourceCollector with metadata: `{source: "dewa-connections", frequency: "monthly", priority: 4, timeout: 180_000}` (3 min for press release scraping)
       - `collect()` implementation:
         a. DEWA publishes press releases about new connections. The collector must find and parse these.
         b. **Strategy A — DEWA press releases page**: Navigate to `https://www.dewa.gov.ae/en/about-us/media-publications/latest-news` via Playwright
         c. Search for recent press releases mentioning "connections" or "customers" or "accounts"
         d. For each relevant press release:
            - Navigate to the full article
            - Extract text content
            - Use regex/text parsing to find numbers: "X new connections", "Y disconnections", area names if mentioned
         e. **Strategy B — If structured data exists**: Check if DEWA publishes monthly statistics reports (PDF or HTML) at `https://www.dewa.gov.ae/en/about-us/media-publications/dewa-publications`. If so, prefer structured data over press release parsing.
         f. Save extracted data as JSON: `/opt/lobsec/data/raw/dewa-connections/{YYYY-MM-DD}.json`
            - Format: `{scrapedAt, source_url, articles: [{title, date, url, connections_new, disconnections, areas_mentioned}]}`
         g. insertRawSource, return result
         h. Close browser in `finally` block
       - **IMPORTANT**: DEWA area-level data may not be available (per research open question #1). If press releases only provide emirate-level aggregates, collect that and document the limitation. Don't fail — collect what's available.
       - **Graceful degradation**: If no relevant press releases found for current month, return `{filePath, rowCount: 0}` which will trigger empty collection error in base class. This is correct behavior — it alerts that DEWA data is unavailable.

    2. **schemas/dewa_schema.py** — Minimal pandera schema:
       - DEWA data is semi-structured (from press releases), so schema is lenient
       - Validate: scrapedAt (str), articles (list), each article has at least title and date

    3. **normalize_dewa.py** — DEWA normalization:
       - Read `{filePath, source, collectedAt}` from stdin
       - Load JSON
       - Extract: `new_connections` and `disconnections` counts per article
       - If area-level data available in text, aggregate by area
       - If only emirate-level: use single metric without area prefix: `dubai|dewa_new_connections`, `dubai|dewa_disconnections`
       - Resample to monthly (most DEWA data is already monthly)
       - Output in standard metric_name format

    **Registry Wiring:**

    4. **Update index.ts** — Register all 7 collectors in the plugin `register()` function:
       ```typescript
       // Import all collectors
       import { DLDSalesCollector } from "./collectors/dld-sales.js";
       import { EjariRentalsCollector } from "./collectors/ejari-rentals.js";
       import { BuildingPermitsCollector } from "./collectors/building-permits.js";
       import { ADRECAbuDhabiCollector } from "./collectors/adrec-abu-dhabi.js";
       import { BayutListingsCollector } from "./collectors/bayut-listings.js";
       import { PropertyFinderListingsCollector } from "./collectors/propertyfinder-listings.js";
       import { DEWAConnectionsCollector } from "./collectors/dewa-connections.js";
       import { normalizeCollectionResult } from "./normalization/orchestrator.js";
       import { initAreaTable } from "./areas/mapping.js";

       // In register():

       registry.register(new DLDSalesCollector(db));
       registry.register(new EjariRentalsCollector(db));

       registry.register(new ADRECAbuDhabiCollector(db));
       registry.register(new BayutListingsCollector(db));

       registry.register(new DEWAConnectionsCollector(db));

       ```
       - Update the `uae_collection_status` tool to show all 7 collectors.
       - Update the "No collectors registered yet" message to actually show status now.

    5. **Update cli.ts** — Wire normalization auto-trigger:
       - After `runAll()` or `runOne()` completes, for each successful collection result, call `normalizeCollectionResult(db, source, result)`.
       - Log normalization results (gap warnings, volume warnings) to stderr.
       - If normalization fails for a source, log the error but continue with remaining sources.
       - Pattern:
         ```typescript
         const registryResult = await registry.runAll();
         for (const [source, result] of registryResult.results) {
           if (result.success) {
             try {
               const normResult = await normalizeCollectionResult(db, source, result);
               console.error(`Normalized ${source}: ${normResult.recordCount} records`);
               if (normResult.gapWarnings.length > 0) {
                 console.error(`  Gap warnings: ${JSON.stringify(normResult.gapWarnings)}`);
               }
             } catch (err) {
               console.error(`Normalization failed for ${source}: ${err}`);
             }
           }
         }
         ```
